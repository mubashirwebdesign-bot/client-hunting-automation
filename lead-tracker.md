## How the daily system works
1. **Find leads** via official Places Search by city + niche (never Maps scraping / GitHub scrapers).
2. **Audit the website** as UI/UX designer + developer + CRO — note the top 3–5 issues only.
3. **Write a 60–90 second script** (compliment → 3 issues → fix → free mockup offer) and record a video.
4. **Upload as Unlisted** to YouTube (never Private — the recipient could not watch it).
5. **Send a very short email** (<80 words, 1 link only, in the footer/signature — not in the body), max **10–15 cold emails/day**.
6. **Follow up Day 3 + Day 7**, then stop. If no valid email, check Instagram / TikTok / Facebook / YouTube, else skip to the next lead.
7. **Only top-scored leads get a video** — others get short text outreach.
